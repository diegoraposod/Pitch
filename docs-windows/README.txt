PITCH · by Diego Raposo
Drone and binaural generator that tunes itself to the sound around you.
VST3 · Windows 10 / 11 (64-bit)

INSTALL
1. Copy the PITCH.vst3 folder to:  C:\Program Files\Common Files\VST3
   (Windows will ask for administrator permission - click Continue.)
2. In Ableton Live: Options > Preferences > Plug-Ins > turn on "Use VST3 Plug-In System Folders" and click Rescan.
3. Find PITCH under Plug-Ins > Diego Raposo and drop it on an audio track.

If Windows SmartScreen shows a warning, click "More info" > "Run anyway".
